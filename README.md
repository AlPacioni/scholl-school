# Bremerhavener maritime Industrie-Website

## Umfang
Professionelle Mehrseiten-Website zur Bremerhavener Werft- und Hafenindustrie vor, während und nach dem Zweiten Weltkrieg.

## Seiten
- `index.html` Überblick
- `before.html` Vorkriegszeit
- `during.html` Kriegszeit
- `after.html` Nachkriegszeit
- `timeline.html` filterbare Zeitleiste
- `sources.html` Quellen und Bildnachweise
- `methodology.html` Methodik und Quellenbehandlung
- `glossary.html` maritime Begriffe
- `about.html` Kontakt und Projektdetails

## Tooling
- `npm run lint` -> grundlegende HTML/CSS-Qualitätschecks via `scripts/lint.ps1`
- `npm run build` -> erzeugt minifizierte Assets via `scripts/build.ps1`

## Ausführen
`index.html` im Browser öffnen.
